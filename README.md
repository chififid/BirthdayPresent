# BirthdayPresent

Фотографии из личных сообщений @BirthdayInstallerBot автоматически сохраняются в `photos/`.
Отправляйте фото или изображения как файлы. Альбомы сохраняются отдельными фотографиями.
Подписи, сведения об альбомах и Telegram-сообщениях сохраняются в `metadata/`.

Загрузчик работает через пользовательскую службу systemd и запускается при входе в систему.
Компьютер должен быть включён, подключён к интернету и не находиться в спящем режиме.
Telegram хранит неполученные обновления не более 24 часов; уже полученная очередь хранится локально.
Стандартный Bot API скачивает файлы до 20 МБ. Крупные файлы останутся в очереди с ошибкой.
Принимаются изображения из всех личных чатов с ботом; не публикуйте ссылку на него.
800 фотографий из `photos/` включены в Git для публикации сайта. Метаданные,
секреты загрузчика и исходный референс `photo.jpg` исключены из Git.

Проверить очередь:

```sh
python3 /home/rb/Programming/BirthdayPresent/telegram_download.py --status
```

Остановить / запустить:

```sh
systemctl --user stop birthday-photo-downloader
systemctl --user start birthday-photo-downloader
```

Журнал: `.telegram/downloader.log`. Токен: `.telegram/token` (доступ только владельцу).
Для смены токена замените содержимое этого файла: загрузчик читает его при каждом запросе.

Документация Telegram: https://core.telegram.org/bots/api#getupdates и https://core.telegram.org/bots/api#getfile

## Сайт с фотомозаикой

Открыть: http://localhost:4180

Главный экран: перемешанная фотомозаика с постоянно пульсирующим сердцем и
расходящимися волнами яркости. Единственная кнопка — «Исследовать».
Порядок перемешивания фиксированный, атлас и оригиналы остаются согласованными.
При включённом уменьшении движения в системе сердце отображается статично.
Отдельный режим исследования: перетаскивание, зум к курсору, pinch-жесты,
кнопки масштаба, открытие оригинала и переход между фото стрелками.
Escape закрывает просмотр; в режиме исследования возвращает к истории.

`site/` содержит HTML, CSS, Canvas-приложение и WebP-атлас превью (около 1,86 МБ).
Крупные фотографии запрашиваются по мере приближения; оригиналы не изменяются.
Сервер отдаёт только `site/` и `/photos/`, секреты загрузчика недоступны через HTTP.
Локальный сервер доступен только на текущем компьютере. Для GitHub Pages
сборка автоматически объединяет `site/` и оригиналы из `photos/` в `_site/`.

## GitHub Pages

В репозитории откройте Settings → Pages и выберите Source → GitHub Actions.
Workflow `.github/workflows/pages.yml` публикует сайт при push в `main`;
его также можно запустить вручную через Actions. На хостинг попадают только
файлы сайта и 800 фотографий. Python-сервер и Telegram-загрузчик там не нужны.
Относительные пути поддерживают адрес вида `https://USERNAME.github.io/BirthdayPresent/`.

Подготовить такую же статическую сборку локально:

```sh
python3 scripts/build_pages.py
python3 -m http.server 4181 --directory _site --bind 127.0.0.1
```

Открыть: http://localhost:4181
Сборка не требует npm или сторонних Python-библиотек. Папка `_site/`,
зависимости и секреты исключены из Git. Для обновления геометрии и атласа
по-прежнему используются отдельные скрипты подготовки ниже.

После добавления новых фото обновить атлас и перезагрузить страницу:

```sh
python3 /home/rb/Programming/BirthdayPresent/scripts/prepare_photos.py
```

Остановить сайт: `systemctl --user stop birthday-present-site`.
Запустить: `systemctl --user start birthday-present-site`.

До первого нажатия клавиши (кроме пробела) на главном экране показывается только сердце.
Клавиша плавно гасит сердце за секунду, затем запускает поздравления с английского; повторные нажатия не перезапускают цикл.
Поздравления идут по очереди: «Happy Birthday!», «С днём рождения!»,
«生日快乐！», «Heri ya siku ya kuzaliwa!», «Alles Gute zum Geburtstag!».

Фотографии остаются неподвижной сеткой. Предварительно рассчитанные маски букв
меняют только яркость целых ячеек, как маска сердца. Высота букв — до 56% доски, китайских иероглифов — до 76%
(с ограничением по ширине на телефоне);
прокрутка непрерывная: фраза входит справа первой буквой, слова читаются в обычном порядке, отдельные буквы подпрыгивают. Скорость —
43% ширины доски в секунду; длительность фразы зависит от её длины.
В исследовании время сценария приостанавливается. Волны повторяют контур сердца.
Локальные шрифты в assets/fonts обеспечивают поддержку всех пяти языков.

На границах сцен яркость плавно возвращается к фону: затухание сердца — 1 секунда,
проявление сердца после текста — 1,05 секунды, затухание/проявление надписей — 0,7 секунды.

Во время поздравлений доска плавно отдаляется до 87% обычного масштаба;
при возвращении сердца восстанавливается исходный масштаб.

## Портрет из фотографий

Сначала встроенным image_gen по референсу `photo.jpg` создан отдельный рисунок
только лица и волос чёрными линиями на белом фоне. Генерация: identity-preserve,
без одежды и фоновых объектов. Полный промпт: `portrait-generation-prompt-v2.txt`.
Готовое изображение: `site/assets/portrait-line-art-v2.png`.

Из рисунка извлекаются центральные линии штрихов (skeletonization), затем
1600 разных координат. Каждый из 800 исходных снимков используется ровно дважды
только в сцене портрета. Новые фотофайлы не создаются, основной атлас остаётся прежним.
Результаты: `site/assets/portrait-contours.svg` и `site/assets/portrait.json`.

После немецкого поздравления камера отдаляется до 48% обычного масштаба,
фотографии собираются в портрет, затем начинается мини-анимация с подарком. Все копии доступны в паузе
для приближения и открытия оригинала.

Быстрый просмотр: http://localhost:4180/?scene=portrait
Рисунок: http://localhost:4180/assets/portrait-line-art-v2.png
Контуры: http://localhost:4180/assets/portrait-contours.svg

Пересобрать геометрию по готовому рисунку:

```sh
python3 /home/rb/Programming/BirthdayPresent/scripts/prepare_portrait.py
```

Используются Pillow, OpenCV, NumPy, SciPy и scikit-image. Исходное фото сохранено
неизменным. Сайт визуально не проверяется; автоматические проверки контролируют
количество копий, геометрию и интерактивное управление.

## Управление показом

- Удерживать левую кнопку мыши на полотне 1,1 секунды: пропустить поздравления и перейти к сборке портрета. Отпускание, движение мыши или потеря фокуса отменяют удержание.
- Пробел: остановить текущую сцену с сохранением позиций и яркости всех фото; доступны перемещение, зум и просмотр оригиналов. Это работает и посреди сборки портрета.
- Повторный пробел: закрыть открытое фото, вернуть камеру и продолжить с остановленного момента.
- В паузе яркость фотографий строго сохраняется при любом масштабе.
- «К поздравлению» по-прежнему сбрасывает показ к сердцу.


Детализация портрета: лицо — 1120 элементов (глаза 320, брови 160, нос 150,
рот 200, контур лица 290), волосы — 480: внешний контур 350, внутренние пряди 130.
Размеры фото зависят от расстояния между точками: 0,85–1,5% высоты портрета на лице,
0,9–2% на волосах, 0,75–0,9% на глазах. На свободных участках фото крупнее;
около черт лица размер ограничен, чтобы сохранить тонкие линии.
Позиции копий назначаются случайно с жёстким расстоянием не менее 18% высоты
портрета между одинаковыми фото; одинаковые файлы определяются по SHA-256,
включая пять дубликатов, добавленных до создания портрета.


## Мини-анимация после портрета

После сборки девушка переводит взгляд вправо и слегка удивляется. Справа
подъезжает близко к портрету коробка, целиком собранная из фото (корпус, лента, крышка и бант).
Крышка поднимается; из коробки вылетают 280 крупных вращающихся фотографий-конфетти тремя всплесками.
Из открытой коробки вылетают два изображения подарков. Снимки портрета и коробки
перестраиваются в рамки, остальные разлетаются в стороны. Переход идёт без затемнения.

Время от начала сборки портрета: сборка 0–5 с, реакция 6–8 с, подъезд коробки
7,35–9,85 с, открытие 10,6–11,8 с, конфетти с 11,8 с. С 14,2 с начинается
переход к двум подаркам, который длится 2,4 с. Удержание ЛКМ пропускает только поздравления до этой сцены.
Пробел сохраняет фото, их яркость и углы поворота на любом этапе. Код геометрии
и времени находится в `site/mini-animation.js`; случайность конфетти фиксированная.

## Выбор подарка

Финал остаётся на общей фотодоске, без заголовков и подписей. Из коробки
одновременно появляются два подарка: слева конная прогулка, справа подводная фотосессия. Фотографии сохраняют свои пропорции; вплотную к ним идут
фигурные рамки из общих снимков, с волнистыми краями и сердечками по углам.
Скрепки из фото находятся отдельно под изображениями, слегка покачиваются
и открывают соответствующие сайты. Их области нажатия остаются неподвижными.

Курсор на доске — стрелка из фотографий. Пробел или «Стоп» фиксирует всю сцену,
включая курсор, рамки и конфетти. Можно перемещаться, приближать и открывать
снимки застывшего курсора. Повторный пробел продолжает с того же момента.
При наведении подарок плавно приподнимается и подсвечивается; количество плиток
рамки и назначенные им фотографии остаются постоянными. Нажатие выбирает его:
второй вариант исчезает, выбранный перемещается в центр за 0,9 с. Только после
завершения перемещения вылетает фотоконфетти; пауза останавливает и этот отсчёт.
В обеих сценах конфетти рисуется позади портрета, коробки и изображений подарков.
«К поздравлению» начинает показ заново. Код геометрии — `site/gift-choice.js`.

Открыть финал сразу: http://localhost:4180/?scene=gifts
Проверки логики без скриншотов:

```sh
node scripts/check_choice_geometry.mjs
python3 scripts/check_gift_choice.py
```
